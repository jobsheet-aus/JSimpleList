PROJECT
-------
Name: JSimpleList
Package: au.com.jobsheet.simplelist
Local project: D:\simplelist
Purpose: Very small native Android app providing Todo and Shopping lists.
Shopping differs from Todo by having a Qty field.

STACK
-----
Android native app
Kotlin + Jetpack Compose
Gradle wrapper
Minimum SDK: 26
Target SDK: 36
Compile SDK: 36.1
AndroidX Core KTX pinned to 1.18.0 because 1.19.0 requires compile SDK 37.
Android Studio bundled JDK 21
Local persistence via SharedPreferences + JSON
No login
No server dependency
No internet permission
Manrope is bundled with the APK

CURRENT STATE
-------------
Working debug app is installed and tested on Android.

Features implemented:
- Todo tab
- Shopping tab
- Shopping Qty field
- Add items
- Tick / untick items
- Delete items
- Edit existing Todo items
- Edit Shopping description and Qty
- Qty defaults to 1
- Qty selects existing value on focus, ready to overwrite
- Completed items remain visible and are sorted below incomplete items
- Local persistence across app restarts
- Pinch gesture changes list/content text size
- Font scale is persisted
- Pinch hint is fixed-size and disappears once the active list has 5 or more items
- Main heading and Todo / Shopping tab headings do not resize with pinch
- List rows are compact/dense
- Item text stays vertically centred with checkbox and Delete
- System status bar, soft navigation buttons / gesture area and keyboard insets are respected
- JSimpleList uses a blue/cyan colour scheme matching the logo
- App uses bundled Manrope
- JSimpleList logo appears in the top-left header
- JSimpleList launcher icon implemented
- Visible app name is JSimpleList

DESIGN / BEHAVIOUR DECISIONS
----------------------------
- Keep the app deliberately small and local-only.
- Todo item fields: description + completed.
- Shopping item fields: Qty + description + completed.
- Shopping Qty defaults to 1.
- Completed items remain visible so they can be unticked.
- Pinch resizes content text, not the app title, tabs or hint.
- Pinch must work regardless of pinch direction; diagonal pinch is normal.
- Use Compose transformable handling rather than custom gesture accumulation.
- Hide the pinch hint once the active list contains 5 or more items.
- Existing items are edited inline.
- Keep list rows compact without making controls fiddly.
- Use Manrope throughout the app.
- Use the JSimpleList logo blue/cyan colour family throughout.
- Keep package ID au.com.jobsheet.simplelist; visible/public name is JSimpleList.
- Repository is intended to become public on GitHub.
- APK is intended to be distributed from jobsheet.com.au.
